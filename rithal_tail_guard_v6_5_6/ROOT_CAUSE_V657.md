V6.5.6 production evidence showed that canonical/reference seam equality is not a valid invariant after a raw-source correction. On SOLUSDT, most direct Binance metrics differed in exactly one of 96 seam rows (mean difference = max difference / 96), while rolling z-scores propagated that corrected row across the window. The immutable canonical enriched archive is a historical output snapshot; a newly rebuilt reference uses the currently corrected raw source state. Comparing those two artifacts and requiring equality rejects the very correction the live overlay needs. V6.5.7 therefore keeps the canonical archive untouched, proves short and long builds against each other, and transactionally replaces only the compact 16K live overlay from a self-contained full-context reference.
