Goal

Add a paper trading engine that:

consumes our existing Shot Plan signals (LONG/SHORT/HOLD)

simulates opening/closing positions on BTCUSDT Perp (15m)

applies fees + slippage + funding

stores all position + trade history

shows equity curve, drawdown, open positions, closed trades

supports single-user only

MUST be deterministic (no randomness)

🚫 No real exchange trading.
✅ Only simulation using market data (mark price / candle prices).

2) Execution Rules (how paper trading works)
2.1 When to open a position

Only open if signal is not HOLD and passes all veto rules already produced by the Shot Plan.

Rules:

Only one position at a time initially (simplify).

If a position is OPEN:

ignore new signals unless:

opposite signal with high confidence triggers FLIP

or position hits stop/take/time-stop

2.2 Entry price

Signal generated at candle close t.
Paper entry should be:

default: open of candle t+1
OR if you have mark price stream:

first mark price after signal timestamp

Add slippage:

entry_price *= (1 + slippage_bps/10000) for LONG

entry_price *= (1 - slippage_bps/10000) for SHORT

2.3 Position sizing (risk-based)

Input config:

risk_per_trade_pct = 0.5% (editable)

max_leverage = 5x (optional for display)

Compute:

risk_usdt = equity * risk_per_trade_pct

stop_distance = |entry - stop|

qty = risk_usdt / stop_distance (convert to BTC)
Cap qty so notional does not exceed a max (optional).

2.4 Fees + costs

Use realistic futures costs:

taker fee (config, e.g. 0.04%)

maker fee (optional)

slippage bps (config, e.g. 1–3 bps)
Funding:

apply funding at funding timestamps if position is open:

funding_paid = notional * funding_rate

long pays if rate > 0, short receives (depends exchange rules)

2.5 Exit logic (priority order per candle)

For each new 15m candle, update open position:

Check in this order (conservative):

Stop loss hit

TP1 hit (partial close 50%)

TP2 hit (close remainder)

Trailing stop rule

Time stop: if bars_open >= time_stop_bars AND pnl < +0.3R → close

Flip rule: opposite signal with confidence > 75% and edge > 3x costs → close & reverse

Stop/TP hit rules using OHLC:

LONG: SL if low <= stop, TP if high >= tp

SHORT: SL if high >= stop, TP if low <= tp
If SL and TP hit same candle → assume SL first (worst case).

Trailing stop:

If trail_mode == kalman:

LONG: trail = fast_kalman - buffer

SHORT: trail = fast_kalman + buffer

buffer = 0.2 * ATR
