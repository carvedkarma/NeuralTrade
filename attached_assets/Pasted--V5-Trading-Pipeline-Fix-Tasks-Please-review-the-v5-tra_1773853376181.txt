### V5 Trading Pipeline Fix Tasks

Please review the **v5 training and inference pipeline** and implement the following improvements and bug fixes.

---

## 1. Fix Risk Normalization Instability (Critical)

Current edge calculation can explode when `mae_R` becomes very small.

Update risk normalization logic in the edge scoring function.

Current pattern:

```
risk = mae_R + eps
edge = p * (mu_R / risk)
```

Replace with:

```
risk = max(mae_R, 0.25)
edge = p * (mu_R / risk)
```

or:

```
risk = np.clip(mae_R, 0.25, None)
```

Goal:

* Prevent extreme edge values
* Stabilize signal ranking

---

## 2. Ensure Side-Aware Edge Scoring Is Always Used

Confirm the pipeline always uses the **side-aware scoring mode**.

Expected logic:

```
abs_mu = abs(mu_R)

edge_long  = p_long  * abs_mu / risk
edge_short = p_short * abs_mu / risk
```

Ensure legacy logic is not used anywhere.

## 3. Fix Walk-Forward Threshold Decay

Current decay:

```
--v5-wf-threshold-decay 0.5
```

This collapses thresholds across folds.

Change logic to:

```
--v5-wf-threshold-decay 0.9
```

or disable decay entirely if fold stability becomes an issue.

## 4. Improve Trade Selection (Symbol Fairness)

```

```

```
Top N per symbol per day
```

instead of:

```

```

Goal:

* Prevent BTC/ETH dominating signals
* Allow smaller coins to generate trades
