PHASE 1 — SOFT “QUALITY” LABELS (MAIN PR-AUC WIN)
========================================================

   - net_mae_r = mae_r - cost_r

Defaults:
   temp = 1.5
Add CLI flags:

   --soft-label-temp 1.5

C) Keep existing binary label y_bin unchanged.
