V5 DESIGN OVERVIEW (must implement)

A) New Targets (continuous, execution-aware)
Add a new target generator that computes for each bar (for the chosen horizon):
- ret_h: close-to-close return at horizon (log-return or pct)
- mfe_h: max favorable excursion within horizon in R units (based on ATR or fixed pip)
- mae_h: max adverse excursion within horizon in R units
- vol_h: realized volatility within horizon (std of returns)
- dd_h: max drawdown within horizon
These MUST be computed WITHOUT leakage (only using future bars within horizon for label, like existing barrier labels do).
Store these as y_v5 = [ret_h, mfe_h, mae_h, vol_h].

B) New Heads (v5 forecaster)
Create a new model class V5Forecaster that reuses the same trunk MLP but adds:
- ret_dist_head: predicts distribution of ret_h using StudentT parameters OR Gaussian mixture (simpler: Normal mu/log_sigma)
- mfe_head: regression for mfe_h (Huber)
- mae_head: regression for mae_h (Huber)
- action_head: logits for action {HOLD, LONG, SHORT} (3-class) OR 2-head (enter + dir). Prefer 3-class to avoid collapse.
- barrier_head (learnable multi-preset): predicts which preset to use among N presets (tight/standard/wide/...) WITHOUT oracle leakage.
- optional: regime_head stays (3-class chop/trend/highvol) if enabled
All outputs must be produced in one forward pass.

C) Loss (v5 composite)
Implement composite loss with stable weights and logging:
- L_ret_nll: negative log-likelihood of ret_h under predicted ret distribution (mu/log_sigma)
- L_mfe: Huber(mfe_pred, mfe_true)
- L_mae: Huber(mae_pred, mae_true)
- L_action: cross-entropy for action label derived from future return + mfe/mae (define rule below)
- L_barrier: cross-entropy for preset selection label derived from which preset maximizes realized R, BUT ONLY in "oracle" research mode. In production training, barrier label must be derived from a "soft target" using realized outcomes but not used at inference unless barrier_head is trained. Implement both modes behind flags.

Default loss weights:
w_ret=1.0, w_mfe=0.25, w_mae=0.25, w_action=0.5, w_barrier=0.25, w_regime=0.1 (if enabled)
Add CLI flags: --v5-w-ret --v5-w-mfe --v5-w-mae --v5-w-action --v5-w-barrier --v5-w-regime

D) Action Label Rule (must be deterministic and documented)
Derive action label using future outcomes (for training only):
- if abs(ret_h) < deadzone or (mfe_h < mfe_min): HOLD
- else if ret_h > 0: LONG
- else: SHORT
Expose CLI: --v5-deadzone (default small, e.g. 0.0005), --v5-mfe-min (default 0.2R)

E) V5 Scoring (money-realistic and normalized)
Replace score for v5 ranking with an execution-aware score computed from predicted distributions:
- p_long, p_short from action_head (softmax)
- expected edge for long: E_long = p_long * (E[ret_h] / (risk_proxy)) - lambda * max(0, -mae_pred)
- expected edge for short: E_short = p_short * (-E[ret_h] / (risk_proxy)) - lambda * max(0, -mae_pred)
- score = max(E_long, E_short)
Where risk_proxy = max(1e-6, mae_pred) or predicted vol.
Add horizon normalization: score /= horizon
Add CLI: --v5-score-lambda (default 0.5), --v5-risk-proxy {mae,vol} default mae.

F) Learnable Barrier Selection (no leakage)
Implement barrier_head inference:
- choose preset = argmax softmax(barrier_head)
- at sweep time, evaluate trades using that chosen preset’s TP/SL parameters (not oracle)
Training modes:
- --v5-barrier-mode fixed (default: uses fixed preset passed by --multi-preset-mode fixed:<preset>; barrier_head ignored)
- --v5-barrier-mode learnable (train barrier_head with "soft" target: probability proportional to exp(k*R_preset) using only labels; NOT using oracle at validation)
- --v5-barrier-mode oracle (research only; logs WARNING; uses best-of-all at training and sweep)
