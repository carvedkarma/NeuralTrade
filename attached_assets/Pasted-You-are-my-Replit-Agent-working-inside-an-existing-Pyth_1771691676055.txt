You are my Replit Agent working inside an existing Python crypto trading system (v5). Implement a new “Drawdown-Adaptive Throttle (DDT)” overlay that keeps model weights + base threshold frozen but adapts entry strictness and sizing gradually based on recent realized performance.

GOAL
- When recent realized R is negative (chop/regime shift), progressively:
  1) raise the effective entry threshold (fewer trades)
  2) reduce position size (lower risk)
- When performance recovers, relax slowly (hysteresis).
- Must be deterministic, testable, and OFF by default. No online learning / no weight updates.

1) ADD CLI FLAGS (default OFF)
Add these to argparse/typer config and print them in run config:

--v5-ddt-lookback-trades (int, default 60)
--v5-ddt-bad-rollr (float, default 6.0)         # rolling sum R <= -bad_rollr => max throttle
--v5-ddt-thr-k (float, default 0.60)            # thr_eff = thr_base * (1 + thr_k*throttle)
--v5-ddt-thr-min (float, default 0.08)
--v5-ddt-thr-max (float, default 0.25)          # HARD CAP to avoid runaway thresholds (e.g. 1.8)
--v5-ddt-size-k (float, default 0.70)           # size_mult = 1 - size_k*throttle
--v5-ddt-min-size-mult (float, default 0.25)
--v5-ddt-alpha-down (float, default 0.30)       # tighten fast
--v5-ddt-alpha-up (float, default 0.05)         # loosen slow
--v5-ddt-warmup-trades (int, default 20)        # don’t throttle until >= N closed trades

2) NEW MODULE: drawdown_throttle.py
Create class DrawdownAdaptiveThrottle with:
State:
- closed_r_history: deque[float] with maxlen lookback_trades
- throttle_state: float in [0,1] (smoothed)
Methods:
- update_on_trade_close(realized_r: float) -> None (append, update rolling sum)
- compute_raw_throttle() -> float:
    if len(history) < warmup_trades: return 0
    rolling_sum = sum(history)
    if rolling_sum >= 0: raw=0
    elif rolling_sum <= -bad_rollr: raw=1
    else raw = (-rolling_sum)/bad_rollr
- step_smooth(raw: float) -> float:
    if raw > state: state = (1-alpha_down)*state + alpha_down*raw
    else:          state = (1-alpha_up)*state + alpha_up*raw
- effective_threshold(thr_base: float) -> float:
    thr_eff = thr_base * (1 + thr_k*state)
    thr_eff = clamp(thr_eff, thr_min, thr_max)
- size_multiplier() -> float:
    m = 1 - size_k*state
    return clamp(m, min_size_mult, 1.0)
