C) MODEL ARCH CHANGE: add VALUE head (E[netR]) while keeping ENTER head
1) Architecture:
   - shared trunk: MLP (existing)
   - enter_head: Linear -> logit (NO sigmoid inside model; apply sigmoid outside)
   - value_head: Linear -> value_logit (regression output predicting net_R expectation)

2) Targets:
   - enter_target: existing binary label (from triple barrier parity)
   - value_target: net_r from triple_barrier (gross_r - cost_r), clipped to [-3, +3] R
     NOTE: value_target should be 0 for HOLD-only samples? No — only compute for labeled opportunities.
     Implement consistent rule:
       - If sample is “enter positive” or “enter negative” per current labeling, it has a realized net_r.
       - value_target is that net_r (can be negative).
     This allows the head to learn expectancy, not just direction.

3) Loss:
   - enter loss: BCEWithLogitsLoss(pos_weight=neg/pos)
   - value loss: HuberLoss (delta=1.0) or SmoothL1Loss
   - total loss: L = enter_loss + λ * value_loss (default λ=0.5)
   CLI flags:
   --value-loss-weight (default 0.5)
   --value-clip (default 3.0)

ACCEPTANCE LOGS EACH EPOCH:

- [TRAIN] enter_bias_init=... (see section D)

- [METRIC] value_mae=... value_rmse=...
- [METRIC] p_enter percentiles (val): p50 p75 p90 p95 p99

E) TEMPERATURE SCALING CALIBRATION (post-train)
Purpose: make p_enter thresholds meaningful across assets.
1) After training finishes, fit temperature T on VAL logits:
   - Collect enter_logits and enter_labels on val
   - Optimize T > 0 minimizing NLL: BCEWithLogitsLoss(logits/T, labels)
   - Save temp_scale_v5.0.json:
     {"temperature": 1.37, "fitted_on": "val", "version": "v5.0_multiasset_calibrated_valuehead"}

2) In inference:
   - Load temperature if file exists
   - Use calibrated logits: logit_cal = logit / T
   - p_enter = sigmoid(logit_cal)
