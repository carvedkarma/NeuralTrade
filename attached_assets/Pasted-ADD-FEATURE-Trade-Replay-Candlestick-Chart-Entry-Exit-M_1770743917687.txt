ADD FEATURE: Trade Replay Candlestick Chart (Entry/Exit Markers)

GOAL
In the Trade Detail popup (modal), show an interactive candlestick chart that displays:
- 15m candles around the trade
- entry marker at entry candle/time
- exit marker at exit candle/time
- horizontal lines for Entry, SL, TP
- shaded region between entry and exit time
This must be accurate (no fake candles).

BACKEND
1) Implement endpoint:
   GET /api/trades/:tradeId/replay?preBars=50&postBars=10
Returns JSON:
{
  trade: {
    id, symbol, side,
    entry_at, exit_at,
    entry_price, exit_price,
    sl_price, tp_price,
    outcome, net_r, pnl_usd
  },
  timeframe: "15m",
  candles: [
    { t: 1700000000000, o: 1.0, h: 1.2, l: 0.9, c: 1.1, v: 1234 },
    ...
  ],
  markers: [
    { t: entry_at_ms, price: entry_price, type: "ENTRY", side: "LONG|SHORT" },
    { t: exit_at_ms,  price: exit_price,  type: "EXIT", outcome: "TP|SL|EXPIRE" }
  ],
  lines: [
    { name: "ENTRY", price: entry_price },
    { name: "SL",    price: sl_price },
    { name: "TP",    price: tp_price }
  ],
  bands: [
    { from: entry_at_ms, to: exit_at_ms, label: "Trade Window" }
  ]
}

2) Data source:
- Use the same candle fetcher you use for live (exchange OHLCV), OR store candles in DB.
- The replay must include candles that cover: [entry_at - preBars*15m, exit_at + postBars*15m]
- Ensure timestamps align to 15m boundaries.

FRONTEND (CHART)
3) Use a proper candlestick library that supports overlays:
Preferred: TradingView Lightweight Charts (lightweight-charts)
Alternative: ECharts candlestick
(Do NOT use a simple line chart.)

4) Build <TradeReplayChart tradeId="..."> component in the modal:
- Fetch /api/trades/:id/replay
- Render candlesticks
- Add markers:
   - ENTRY marker: green up arrow for LONG, red down arrow for SHORT
   - EXIT marker: label with outcome (TP/SL/EXPIRE)
- Add horizontal price lines:
   ENTRY (dashed), SL (red), TP (green)
- Add a shaded band between entry and exit timestamps.

5) UX requirements:
- Tooltip on hover shows OHLCV
- Toggle: show/hide SL/TP lines
- Toggle: show/hide volume (optional)
- If trade is still OPEN, show band from entry to last candle and label “OPEN”.

6) Verification:
- Log “Replay candles loaded count=X range=...”
- Assert entry_at and exit_at fall within candle range. If not, show “Replay data missing”.

BONUS (optional but valuable)
- Add small panel beside chart:
  - bars held, MFE/MAE if computed, net_r, pnl_usd
- Add “jump to entry” button that centers chart on entry candle.
