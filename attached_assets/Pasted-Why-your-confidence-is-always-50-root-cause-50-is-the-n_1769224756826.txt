What confidence SHOULD represent (important)

Confidence is not direction probability.

Confidence should answer:

“How sure am I that this is a tradable situation?”

It should combine:

Directional probability (Up/Down)

Regime clarity

Edge vs costs

Pattern support & maturity

Model agreement (dispersion)

Volatility context

How confidence SHOULD be computed (simple & correct)
Step 1: Base directional confidence
base = max(prob_up, prob_down)


In your screenshot:

base = 64%

Step 2: Regime clarity multiplier

Example:

regime_conf = 1 - chop_probability


Here:

chop = 8%

regime_conf ≈ 0.92

Step 3: Edge vs cost penalty

If edge ≤ costs → confidence must drop hard.

Example:

edge_factor = clamp((edge - costs) / costs, -1, +1)


In your case:

edge = -0.08%

costs = 0.13%

edge_factor < 0 → strong penalty

Step 4: Pattern maturity factor

If patterns exist but immature:

pattern_factor = maturity_score   // 0..1


Early systems often have:

pattern_factor ≈ 0.2–0.4

Step 5: Model agreement (dispersion)

If models disagree:

agreement = 1 - stddev(model_probs)


If half say HOLD, half say UP → agreement low.

Step 6: Final confidence
confidence =
  base
  * regime_conf
  * agreement
  * pattern_factor
  * edge_penalty


Then clamp to [0, 100].
