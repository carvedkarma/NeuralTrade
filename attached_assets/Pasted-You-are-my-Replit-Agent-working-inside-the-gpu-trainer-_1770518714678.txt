PHASE 1 — FIX THE BIGGEST ISSUE: LABEL ↔ SWEEP PARITY
========================================================
Problem:
- Labels are created using true triple-barrier with future HIGH/LOW and ATR(14) from OHLC.
- Current ENTER_TRADING_SWEEP still uses close-to-close forward_returns and/or a proxy ATR (std of returns) in some paths.
This makes expectancy/PF/Sharpe unreliable and causes “edge appears then vanishes”.

Task 1.1: Implement a single source of truth triple-barrier simulator
Create module: training/triple_barrier.py with:

1) compute_atr_14(df):
   - Must match the ATR method used in labeling (true range with OHLC).
   - Return a vector aligned to df rows.

2) triple_barrier_outcome_for_index(df, i, side, atr_i, tp_mult, sl_mult, horizon, r_min_expiry):
   - entry = close[i]
   - tp_dist = tp_mult * atr_i
   - sl_dist = sl_mult * atr_i
   - LONG: tp = entry + tp_dist, sl = entry - sl_dist
   - SHORT: tp = entry - tp_dist, sl = entry + sl_dist
   - Walk forward j=1..horizon using future high/low:
     - If TP hit first => outcome="TP", r = +tp_dist/sl_dist
     - If SL hit first => outcome="SL", r = -1
     - If both hit same bar, resolve consistently with labeling:
       - Use “worst-case” assumption (SL first) unless labeling uses another rule; match it exactly.
   - If expiry:
     - exit = close[i+horizon]
     - pnl = (exit-entry) for LONG, (entry-exit) for SHORT
     - r = pnl / sl_dist
     - if r >= r_min_expiry => outcome="EXP_WIN" else "EXP_LOSS"
   - Return (outcome, r)

3) triple_barrier_batch(df, indices, sides, tp_mult, sl_mult, horizon, r_min_expiry):
   - Vectorized loop ok (clarity > micro-optimizations).
   - Returns arrays: outcomes, r_values.

PHASE 2 — FIX SHARPE (CURRENTLY MISLEADING)
========================================================
Problem:
- Sharpe is being annualized as if trade returns were per-bar returns, causing huge negative numbers.

Task 2.1:
- Remove Sharpe OR compute trade-based Sharpe properly:
  sharpe = mean(r_values)/std(r_values) * sqrt(trades_per_year)
  trades_per_year = trades / (val_days) * 365
  val_days = val_bars / 96.0 (15m bars/day)

If std is near zero, set sharpe=0.
