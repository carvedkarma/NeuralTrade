Label definition v4.7 (strict, tradeable):
For each bar, compute best_R exactly as before (TP/SL/expiry within horizon; same TP=2.0*ATR, SL=1.5*ATR, horizon=16 bars default).
Then set:
- ENTER=1 only if:
   (A) TP was hit BEFORE SL within horizon
   OR
   (B) expiry happened but best_R >= r_min_expiry_strict
And ALSO require:
   best_R >= r_min_enter (default 0.8)
This blocks weak “almost wins” and reduces positives.

Defaults:
- r_min_enter = 0.8
- r_min_expiry_strict = 1.0
- disable counting “expiry small win” as positive
