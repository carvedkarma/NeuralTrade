1) Upgrade your data from “candles” to “market microstructure”

Candles alone can work, but “peak” requires more information density.

Add (in priority order):

Order book + trades (L2/L3): imbalance, spread, depth, cancel rates, aggressive buy/sell flow

Funding rate + open interest + liquidation data (per exchange if possible)

Cross-exchange basis (Binance vs Bybit vs OKX)

Perp vs spot flows (spot volume leading perp moves is meaningful)

Session / calendar features (UTC hour, day-of-week, major macro windows)

This is where most edge comes from.

2) Stop training “direction classes” as your primary objective

For peak performance, classification is usually a helper, not the core.

Train multi-task outputs:

μ = expected future return over 4h (regression)

σ = uncertainty (predict variance or use quantiles)

P(move > cost) = probability net move beats fees/slippage

Optional: quantiles (p10/p50/p90) to get asymmetric risk

Then your signal is computed as:

edge = μ − cost

confidence = edge / σ

enter only if confidence clears your target frequency

This gives “strong signals” automatically.

3) Use walk-forward evaluation like a hedge fund

Most “amazing” results die live because evaluation is wrong.

Must-have protocol:

Purged time splits (you already do this)

Walk-forward: train on window A, test on next window B, roll forward

Per-regime reporting: trend, range, high-vol, low-vol

After-cost PnL with realistic fills (maker/taker logic + spread + slippage)

Measure: expectancy, drawdown, tail losses, not accuracy

If you can’t beat costs in walk-forward, don’t scale GPUs.

4) Ensemble + mixture-of-experts beats “one huge model”

If you want “no one else has created,” do this:

A) Expert models by regime

Train specialists:

trend expert

mean-reversion expert

volatility-breakout expert

news-shock / chaos expert (often “don’t trade”)

Then train a gating network that selects/weights experts based on regime features.

This is how you get both aggressive and accurate.

B) Timeframe experts (without mixing raw timeframes)

Keep separate experts for 1m/5m/15m that feed into the gate.
Don’t shove all TFs into one soup unless you really know what you’re doing.

5) Pretrain like a foundation model (this is where GPUs matter)

If you’re serious about “peak,” use big GPUs for self-supervised pretraining:

Pretrain an encoder on billions of timesteps using tasks like:

masked time-series modeling (mask segments, predict them)

next-k-step distribution prediction

contrastive learning across assets (same regime, different asset)

regime clustering objectives

Then finetune on your trading objective (μ/σ, P(move>cost)).

This is a huge unlock.

6) Execution is half the edge (even if you’re not auto-trading yet)

A model can be “right” but untradable.

Peak system includes:

maker vs taker decision per signal strength/urgency

slippage model (volatility + spread dependent)

position sizing using uncertainty (bounded Kelly / risk parity)

kill switch + cool-down on drawdown/loss streaks

“don’t trade during” macro windows (FOMC/CPI) or spike regimes

Even as a signal service, you should output:

action

confidence

expected move

expected slippage/cost

suggested order type

7) Add alternative data the right way

News/social can help, but best use is risk filter, not directional predictor:

“raise uncertainty” / “tighten thresholds”

“disable during major events”

detect abnormal attention spikes

If you use it to predict direction directly, it often overfits.

The fastest “peak upgrade” plan for you (no huge rewrite)

If I had to pick 3 upgrades that give the biggest jump:

Switch to μ/σ (regression + uncertainty) and score = (μ − cost)/σ

Walk-forward + after-cost evaluation as the only success criterion

Regime mixture-of-experts (trend vs mean reversion vs breakout) with a gate

That can outperform most retail/pro systems without needing exotic data.
